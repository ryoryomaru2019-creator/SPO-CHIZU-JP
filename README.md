# サカ地図 (SAKACHIZU) - サッカー会場場所当てWebゲーム

『サカ地図』は、出題されるサッカー会場の問題文を読み、日本地図上に予想ピンを配置して正解地点との誤差距離および獲得スコアを競うWebゲームです。PC・スマートフォン（縦画面優先）の双方で快適にプレイできるように設計されています。

---

## 🚀 特徴

- **Google Maps API 完全不使用**:
  ゲーム内にはGoogle Maps API（JavaScript API、Street View API、Static APIなど）を一切埋め込んでおらず、APIキーも不要です。回答確定後、公式のGoogle Maps外部リンク（Street Viewおよび通常地図）を生成し、別タブで確認できる仕様としています。
- **Leaflet による地図抽象化レイヤー**:
  地図表示処理は `MapProvider` インターフェースで抽象化されており、Leaflet以外の地図ライブラリへの差し替えも容易な設計です。
- **レスポンシブデザイン**:
  PCでは横幅を活かした左右2カラム配置（左：問題・結果、右：地図）、スマートフォンでは地図をメインにした縦レイアウトを採用しています。
- **オフライン距離・スコア計算**:
  Haversine公式による高速かつ正確な誤差計算を行い、100m以内なら満点5,000点などの距離に応じたスコアリングを実施します。

## 💻 ローカル起動方法

### 1. 依存パッケージのインストール

```bash
npm install
```

### 2. 環境変数の設定

`.env.example` をコピーして `.env` を作成します（未設定時もデフォルト値で動作します）。

```bash
cp .env.example .env
```

### 3. 開発サーバーの起動

```bash
npm run dev
```

起動後、コンソールに表示されるURL（通常 `http://localhost:5173`）をブラウザで開いてください。

## 🌐 Google Maps 外部リンク方式について

### Google Maps API を使用しない理由
- 課金リスクやAPIキー流出リスクを回避する
- 外部APIへの通信待ち時間をゼロにし、完全な静的ホスティングを可能にする
- 利用者にStreet View等の公式体験をGoogleのWebサイト上で安全に利用してもらう

### 生成されるURLの形式

1. **回答地点のStreet View**
   `https://www.google.com/maps/@?api=1&map_action=pano&viewpoint=緯度,経度`
2. **正解地点のStreet View**
   `https://www.google.com/maps/@?api=1&map_action=pano&viewpoint=緯度,経度`
3. **正解地点の通常地図検索**
   `https://www.google.com/maps/search/?api=1&query=緯度,経度`

すべて `target="_blank"` および `rel="noopener noreferrer"` で安全に別タブで開かれます。

## 📝 問題データの追加・編集方法

問題データは `src/data/questions.json` に記述されています。

### データ構造

```json
[
  {
    "id": "q001",
    "title": "日本のメインスタジアムを探そう",
    "question": "2020年東京大会のメイン会場であり、サッカー日本代表戦や天皇杯決勝も開催される『国立競技場』はどこにあるでしょうか？",
    "hint": "東京都新宿区の明治神宮外苑エリアに位置しています。",
    "category": "stadium",
    "answer": {
      "name": "国立競技場 (JAPAN NATIONAL STADIUM)",
      "latitude": 35.6778,
      "longitude": 139.7145
    }
  }
]
```

### 座標の取得・登録方法
1. ブラウザ等で目的のスタジアムの緯度（latitude）と経度（longitude）を10進数で確認します（例: 国立競技場は 北緯 35.6778, 東経 139.7145）。
2. `latitude` に -90 〜 90 の範囲の数値、`longitude` に -180 〜 180 の範囲の数値を設定します。
3. `npm test` を実行すると、追加した問題のデータ構造と座標の妥当性が自動検証されます。

## ⚠️ 本番公開時の注意事項

1. **公開地図タイルの利用規約の遵守**:
   デフォルトで使用している OpenStreetMap の公開タイルサーバー（tile.openstreetmap.org）は、個人開発や小規模アクセス向けに無償提供されています。
   大規模な商用利用や大量アクセスが想定される場合は、Mapbox、MapLibre、Stadia Maps、Protomaps 等の商用タイルプロバイダーまたは独自ホスティングタイルサーバーへの切り替え（`.env` による設定）を行ってください。
2. **Google Maps 側の仕様依存**:
   外部リンク先の Street View は、Google側でストリートビューパノラマ写真が撮影・公開されている地点でのみ表示されます。山間部やピッチ内などストリートビューデータが存在しない地点の場合、Google Mapsは自動的に近隣の画像や周辺地図にフォールバックします（ゲーム内のリンクボタン上にもその旨の注意文を明記しています）。
3. **静的ホスティングのキャッシュ**:
   `dist/` 以下のファイルは静的アセットです。Webサーバー（Nginx, CloudFront, Netlify, Vercel 等）で配信する際は、HTMLファイルには `no-cache`、ハッシュ付きJS/CSSには長期キャッシュを設定することを推奨します。

## 🛠️ 管理機能・拡張機能の使い方

### 1. 問題管理画面 (`/admin/questions`)
- トップ画面の「⚙️ 問題管理画面」ボタンまたは直接 `/admin/questions` にアクセスすることで利用できます。
- **タブ切り替え機能**:
  - **📋 問題データ管理**: 会場名・タイトル・タグでの検索、カテゴリ・難易度・公開非公開での絞り込み、新規作成・編集・複製・削除、JSONインポート/エクスポート。
  - **⚙️ ゲームルール・パラメータ設定**:
    - **⏱️ タイムボーナス＆制限時間**: 最大ボーナス点、ボーナス減衰秒数、1問あたりの制限時間（タイムアタック: 30秒 / 60秒 / 90秒 / 120秒 / 無制限）。
    - **🎯 距離スコアリング**: 満点スコア（1000〜10000点）、満点許容誤差（0.05〜5.0km）、0点になる最大距離。
    - **🌍 GeoGuessr風チャレンジ設定（オススメ）**: 地図ドラッグ移動の許可/禁止（No Move）、地図ズームの許可/禁止（No Zoom）、ヒント表示の許可/禁止（No Hints）、難易度ボーナス倍率（初級1.0x / 中級1.2x / 上級1.5x）。
- **保存優先順位**: `localStorage` に保存された設定・問題データが最優先され、初期データへのワンクリックリセットも可能です。

### 2. ランダム出題 & カテゴリ選択
- スタート画面で「カテゴリ」「難易度」「出題問題数（5問 / 10問 / 全問）」「ランダム出題（シャッフル）」を選択できます。
- 非公開設定（`isPublished: false`）にされた問題は通常ゲーム出題から自動的に除外されます。
- Fisher-Yatesアルゴリズムにより重複のない公平なシャッフルが行われます。

### 3. プレイ結果履歴 (`/history`)
- ゲーム完了時に自動的に `localStorage` にスコアや正解会場、各問題の誤差・Google Mapsリンクが記録されます。
- 過去の履歴を一覧・展開して確認でき、個別削除や全履歴の一括削除も可能です。

### 4. ピン決定操作 & Result暗転機能
- **ピン決定**: 地図クリックで仮ターゲットを移動し、1秒停止後に現れる「ここに決定」ボタン、またはダブルクリック/ダブルタップで即時確定します。
- **ターゲット表示ON/OFF**: 地図右上の「🎯 ターゲット」ボタンで切り替え可能（設定はlocalStorageに保持）。
- **Result暗転**: 正解画面で「💡 地図の暗さを解除」/「🌙 地図を暗くする」ボタンで暗転とスポットライト光のON/OFFが可能です。

### 5. 海外地図の日本語カタカナラベル（🌐 表示中：日本語 / 現地語 切り替え）
- 地図上部の「🌐 表示中：日本語 / 現地語」ボタンでワンクリック切り替えが可能です。
- **多段階ズーム連動（大陸 → 国名 → 都市名）**:
  - **世界ズーム (Zoom 2〜3)**: 「ヨーロッパ」「アジア」「南アメリカ」「アフリカ」などの大陸名ラベルを表示。
  - **地域ズーム (Zoom 4〜6)**: FIFA加盟国・地域協会（欧州、南米、北中米、アジア、アフリカ、オセアニア各国の代表国）の日本語国名ラベルを表示。
  - **詳細ズーム (Zoom 6以上)**: 主要サッカー都市（バルセロナ、マドリード、ロンドン、パリ、ミュンヘン、ミラノ、サンパウロなど）のカタカナ都市名ラベルを表示。
  - ラベルにはクリック透過（`pointer-events: none`）が施されており、ピン打ちや地図移動を一切妨害しません。

### 6. カウントダウン & タイムボーナス
- 問題出題時に地図を保護するスタンバイ状態と「🚀 問題スタート！」ボタンを設置。
- スタートボタンを押すと「３，２，１、GO!」のカウントダウン演出を経て問題文と地図がアンロックされます。
- 地図下部に固定幅・等幅フォント（`tabular-nums`）のタイマー（`xx分xx秒xxxx` 形式）が表示され、素早く回答するほどタイムボーナス（最大1,000点）が加算されます。ボーナスタグには「BONUS」のラベルが付きます。

### 7. 中断・リスタート操作（🏠️ & 🔄）
- ゲーム画面のヘッダーに「🏠️ タイトルへ」「🔄 最初から」ボタンを常設。
- 誤操作を防ぐ確認モーダル（「ゲームを終了してタイトルに戻りますか？」「最初からやり直しますか？」）で安全に中断・再挑戦が可能です。

### 8. メニューサイドバーの開閉ツマミ（PC・スマホ完全対応）
- パネルと地図の境界線（PCではパネル右上端、スマホではフローティングボタン）に「◀ 隠す / ▶ メニュー」の開閉ツマミを設置。
- ツマミをクリックするとサイドバーが左にスライド収納（スマホでは縦に折りたたみ）され、地図が画面いっぱいに広がります。
- 隠れた状態でも画面端のツマミ（「▶」）からいつでも再展開できます。
- 開閉時には地図の自動リサイズ（`invalidateSize`）が発火し、全画面に地図タイルが綺麗に即時補完されます。

### 9. Google Maps外部リンク（周辺マップ / ストリートビュー 左右2択UI）
- 結果画面のGoogle Maps外部リンクを横並び2分割の直感的なUIに改善。
- 正解地点および回答地点それぞれについて：
  - **左側**: `🗺️ 周辺マップ`（Google Maps通常地図）
  - **右側**: `📷 ストリートビュー`（Google Street Viewパノラマ）
  の2択からワンタップで選択して別タブで開くことができます。
